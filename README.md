# 💕 Lovely Lines

미드를 보며 마음에 든 대사를 모으고, 원어민 발음으로 따라 말하고, 잊을 때쯤 복습하는 **우리 둘의 영어 공부 앱**이에요.

## 주요 기능

- **🏠 홈:** 둘의 🔥 연속 학습, ✨ 오늘의 대사, 💞 이번 주 커플 퀘스트(둘이 합쳐 10번 복습), 지금 공부하는 사람 바꾸기
- **📺 에피소드:** 드라마·시즌·화별 정리, 본 날짜·👫 같이 봄·별점·한 줄 감상
- **💬 대사장**
  - 대사 저장: 장면 사진, 영어 대사, 외우고 싶은 표현(단어를 눌러 고르기), 뜻, 말한 사람, 태그, 메모
  - 즐겨찾기·태그 필터·검색
- **🗣️ 말하기 연습 3단계**
  - ① 원어민 음성 듣기(보통·0.7배·3번 반복)
  - ② 키보드 🎤 받아쓰기로 따라 말하면 단어별로 채점
  - ③ 내 상황으로 바꿔 말하기
- **🔁 복습**
  - 뜻을 보고 영어로 떠올리기(빈칸·힌트)
  - 몰라요(내일) / 헷갈려요(며칠 뒤) / 알아요(1주 뒤) 간격 반복
- **💞 커플 퀴즈 대결:** 한 휴대폰으로 번갈아 3지선다 퀴즈
- **⚙️ 설정:** 우리 둘 이름·이모지, 음성 속도, 색감 13가지, 글씨체 6가지, 백업(사진 포함)

> 대사는 직접 적어 넣어요. 드라마 대본이나 자막은 저작권 때문에 앱에 미리 넣지 않아요.
> 💡 자막이 나올 때 TV를 찍고, 사진 앱에서 자막을 꾹 누르면 글자가 복사돼요(아이폰 '텍스트 인식').

## 휴대폰에서 쓰는 법

1. 앱 주소(https://dennizhanna218.github.io/Lively-Lines/)를 열어요.
2. 홈 화면에 추가해요.
   - **아이폰:** Safari 공유 버튼 → '홈 화면에 추가'
   - **안드로이드:** Chrome ⋮ → '홈 화면에 추가'
3. 앞으로는 홈 화면 아이콘으로만 열어요(열린 곳마다 기록이 따로 저장돼요).

## 참고한 인기 앱

| 앱 | 배운 점 | 반영 |
|---|---|---|
| Language Reactor / Lingopie | 문맥과 함께 저장 | 장면 사진 + 대사 카드 |
| Cake | 매일 짧은 표현 하나, 반복 말하기 | 오늘의 대사 |
| ELSA / Speak | 말하면 바로 피드백 | 받아쓰기 채점, 바꿔 말하기 |
| Duolingo | 연속 기록, 친구 퀘스트 | 커플 연속 학습, 커플 퀘스트 |
| Anki | 간격 반복 | 복습 일정 |

## 구조 (개발 참고)

```
App.tsx                    탭(홈/에피소드/대사장/복습) + 위에 쌓이는 화면
src/nav.tsx                화면 이동
src/types.ts               데이터 구조 (드라마·에피소드·대사·복습 일정)
src/srs.ts                 간격 반복 복습, 연속 학습, 커플 퀘스트 계산
src/speaking.ts            따라 말하기 채점 (단어 비교)
src/storage/               저장(data.ts), 앱 전체 기록(DataContext), 설정(settings.ts), 백업 파일
src/platform/              웹/네이티브가 다른 부분: 음성(speech), 장면 사진(photoStore), 브라우저 배경색 등
src/settings/              색감 테마, 글씨체, 설정 공유
src/screens/               화면들
src/components/            공통 UI 부품, 대사 카드
```

```bash
npm install          # 처음 한 번
npm run web          # 내 컴퓨터에서 웹으로 실행
npm run typecheck    # 타입 검사
npm run build:web    # 웹 배포용 빌드 (dist/)
```

`main`에 머지하면 GitHub Actions가 GitHub Pages로 자동 배포해요(`.github/workflows/deploy-web.yml`).
처음 한 번은 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿔야 해요.

### 네이티브 앱으로 전환할 때
- 장면 사진: `src/platform/photoStore.ts`에 `expo-image-picker` + `expo-file-system`을 넣어요.
- 말하기 채점: 네이티브 음성 인식으로 받아쓰기를 대신할 수 있어요.
- 원어민 음성: `expo-speech`로 이미 연결돼 있어요.
